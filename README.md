# VendeMais CRM Frontend

Frontend React + Vite do CRM VendeMais, integrado ao backend local em `http://localhost:8080`.

## Como rodar

1. Instale as dependencias com `npm install`
2. Confira o `.env`:
   `VITE_API_BASE_URL=http://localhost:8080`
3. Inicie em desenvolvimento com `npm run dev`
4. Gere o build com `npm run build`

## Stack

- React 19 + Vite
- TypeScript
- React Router
- Axios
- TanStack Query
- React Hook Form + Zod
- Zustand
- Sonner
